# 操作录制

点击悬浮球展开面板，选择“录制操作 · 坐标 / 图片”（工具页也提供入口）。输入新任务名称、录制模式和点击截图边长（默认 100 像素，可设置 20～500），授予悬浮窗、无障碍与截屏权限后准备录制。MediaProjection 应选择共享整个屏幕。

“记录坐标”为默认模式：坐标点击可执行，找图代码被注释。“记录图片”模式：在指定范围找图后点击，原始坐标代码被注释。滑动在两种模式下均保留坐标轨迹。

两种模式的每一步代码（包括滑动）都会显式保留 `var regionN = [left, top, width, height];`，坐标模式下该范围声明也在注释块之外；找图代码直接复用它。

切换到目标应用，点击左下角靠底的录制条“开始”。录制条显示步骤数和最近操作，拖动标题可以调整位置。单指点击、长按、滑动均在松手后向目标应用实际派发；等待录制条重新出现再操作下一步。“暂停”期间可以自由切换应用，暂停时间不计入任务。“完成”或通知栏的“完成并保存”会生成任务并返回任务列表。

任务目录包含：

- `task.js`：按所选模式执行；`sleep` 保存前一步完成至下一步开始的间隔，注释另记相邻操作开始的间隔及操作持续时间。
- `images/step_001.png` 等：点击或长按前的局部截图，默认 100×100。靠边时移动裁剪区域以保留尺寸，并记录原点击点相对于模板中心的偏移。
- `contexts/step_001.png` 等：每一步操作前以起点为中心截取的 600×600 页面范围图，屏幕边缘向内平移，小屏幕按实际大小裁剪。
- `recording.json`：录制模式、操作类型、坐标轨迹、时长、间隔、模板裁剪范围、`searchRegion: [left, top, width, height]` 及页面范围图路径。
- `config.json`：任务名称、步骤数、录制分辨率，默认执行一次。

找图代码使用 `images.findImage(screen, template, { threshold: 0.9, region: regionN })`，只搜索本步骤记录的 600×600 范围，降低匹配开销。切换执行方式时，先注释当前方式，再启用另一种，避免执行两次。找图返回模板中心，生成代码已补偿屏幕边缘裁剪带来的偏移，读取的图片会在使用后释放。

任务列表的“⋮”菜单支持“重命名”和“删除任务”。重命名会保留脚本、素材和历史，并将定时任务迁移到新名称（延时从改名后重新计算）。删除需确认，并会取消定时任务、删除整个任务目录。内置任务被删除或改名后不会在重启时自动补回旧名称。

录制仅在系统手势完成回调后记入步骤；截屏失败时不派发该点击，手势失败或取消时暂停并提示，不自动重试。系统回调表示触摸派发完成，不能保证目标应用的业务结果，需观察目标界面。已完成的步骤即时保存，空录制不生成任务。录制与脚本运行互斥。

当前支持单指操作，单次不超过 60 秒。滑动保留采样轨迹和总时长，曲线使用 `gesture`。系统导航按钮、系统手势和暂停期间的操作不录入。切换屏幕方向会暂停，继续前需恢复原方向；播放使用实际像素坐标，应保持录制时的分辨率、方向和起始界面。

部分系统设置或受保护页面会主动隐藏普通悬浮窗；录制条不可见时，请勿继续录制操作，应返回允许显示悬浮窗的页面。带安全保护的画面也可能不允许截屏。
